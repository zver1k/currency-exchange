Простой и аккуратный конвертер валют на React с ручным запуском расчёта
и обработкой ошибок.\
Работает через публичный **Frankfurter API**.

------------------------------------------------------------------------

## 🚀 Возможности

-   выбор валюты
-   ввод суммы
-   проверка корректности данных
-   запрет конвертации одинаковых валют
-   индикаторы загрузки
-   обработка ошибок сервера
-   загрузка списка валют при старте приложения

------------------------------------------------------------------------

## 🛠 Стек технологий

-   **React (Hooks)**
-   **JavaScript (ES6+)**
-   **Fetch API**
-   **Frankfurter API**
-   **CSS**

------------------------------------------------------------------------

## 📦 Установка и запуск

``` bash
git clone https://github.com/zver1k/currency-exchange.git
cd currency-exchange
npm install
npm run dev
```

------------------------------------------------------------------------

## ⚙ Используемый API

Публичный API:

    https://api.frankfurter.app/

Конвертация:

    latest?amount={amount}&from={currency}&to={changeCurrency}
